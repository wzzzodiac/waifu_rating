# Waifu Rating Machine 3000

A deliberately unserious single-page browser experiment that previews an uploaded image and produces a random "scientific" rating.

## Features

- Local image selection and preview
- Random score between 70 and 99
- Random result commentary
- Short fake analysis delay for presentation
- Responsive dark engineering-lab interface
- No uploads to a server

## Privacy

The selected image is read locally in the browser with `FileReader`. There is no backend, API call or image storage.

## Tech

Everything lives in a single `index.html` file using plain HTML, CSS and JavaScript.
